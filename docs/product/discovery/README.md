# Discovery source material

**Status:** source material, not requirements.

This folder keeps the early discovery inputs that ShortList's requirements were
drawn from. Nothing here is a requirement, a design decision or an approved
public claim. Scope is owned by [REQUIREMENTS.md](../REQUIREMENTS.md); where
anything here differs, REQUIREMENTS wins.

## Prices were never approved

Prices in these files (for example NZ$47, NZ$197 and NZ$500) are early ideas.
None has been approved. The paid offer and pricing decision is still open in
GitHub #40.

## Two overlapping drafts

Two files here are early versions of the MVP requirements and overlap with each
other and with the product-level candidate:

- [GEO_Check_MVP_Requirements.md](GEO_Check_MVP_Requirements.md): the original
  "GEO Check" draft, written for Auckland service businesses.
- [MVP_REQUIREMENTS_CANDIDATE.md](MVP_REQUIREMENTS_CANDIDATE.md): notes on that
  draft plus owner clarifications from 4 October 2026.

Do not confuse the second file with
[`docs/product/MVP_1_REQUIREMENTS_CANDIDATE.md`](../MVP_1_REQUIREMENTS_CANDIDATE.md),
the historical decision record behind REQUIREMENTS. Since then ShortList has
become a global assessment, and the Auckland focus no longer applies.
