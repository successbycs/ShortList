# Model Policy

**Status:** deferred template | **Owner:** AI owner | **Update:** model selection changes.

Choose models by documented capability, cost, privacy, latency, evaluation, and fallback needs. Pin/record model version where supported; do not infer safety from a model name.

This is template guidance for the root Python harness. ShortList's live AI use is
the GEO assessment in `apps/web`, which calls the OpenAI Responses API; see
[apps/web/README.md](../../apps/web/README.md) and the
[GEO assessment prompt](../product/prompts/GEO_ASSESSMENT_V1.md).
